# java-lotto-precourse

# 구현할 기능 정리

## 로또 초기 설정

- 로또 금액 입력받기
    - 로또 금액으로 로또 갯수 정하기
- 당첨번호 입력받기
    - 당첨번호 Class를 만들고 번호 저장해두기
- 보너스 번호 입력 받기
  - 당첨번호 Class에 번호 저장해두기

## 로또 구매하기
- 로또 갯수에 따라 무작위 번호 가져오기
    - 무작위 번호 출력하기
    - 무작위 번호 저장하기

## 당첨 내역
- 당첨내역 계산하기
  - 일치 갯수, 보너스 볼에 따라 일치 갯수 출력하기
  - 수익률 출력하기


## 예외 찾기
- 로또번호 예외처리하기
- 로또 구입 금액 예외처리하기

## 테스트 코드 작성하기
- 로또번호 예외처리 관련 테스트 케이스 작성하기
- 구입금액 관련 테스트케이스 작성하기
